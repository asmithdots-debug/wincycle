# WinCycle

Маленькая нативная утилита для macOS: подсветка активного окна затемнением остальных.

## Зачем

В macOS такой настройки нет вовсе, а сторонние решения (вроде HazeOver) либо платные, либо ненадёжные, либо тянут за собой лишние возможности, которые не нужны.

WinCycle делает это сам, без внешних зависимостей и без единого запрашиваемого разрешения.

## Что умеет

**Подсветка активного окна**

Затемняет все окна, кроме активного — прямая замена платным приложениям вроде HazeOver. Включается и настраивается через значок в строке меню:
- вкл/выкл;
- сила затемнения — ползунок от 0 до 100%.

Если реальное окно на экране всего одно, подложка сама прячется — сравнивать не с чем, и тёмная рамка по краям только мешала бы.

## Разрешения

**Никаких.** Список окон и их геометрия берутся из публичного API `CGWindowListCopyWindowInfo`, который не требует ни «Универсального доступа» (Accessibility), ни «Записи экрана» — WinCycle только сравнивает окна между собой и переставляет собственные прозрачные подложки, ничьими чужими окнами не управляет.

## Установка

Готовых сборок пока нет — только исходники, ставится через компилятор Swift, который уже стоит в macOS вместе с Command Line Tools (полноценный Xcode не нужен).

```sh
git clone https://github.com/<your-username>/wincycle.git
cd wincycle
./setup-signing.sh   # один раз — создаёт постоянный сертификат для подписи
./build.sh           # собирает, подписывает, устанавливает в ~/Applications, запускает
```

### Про постоянную подпись

`setup-signing.sh` создаёт самоподписанный сертификат в отдельной связке ключей (`~/Library/Keychains/wincycle.keychain-db`) и добавляет его в доверенные без пароля администратора. Это не для важности — просто чтобы `codesign -s -` не менял отпечаток подписи при каждой пересборке, и Gatekeeper не переспрашивал заново на каждый новый запуск.

### Автозапуск

```sh
cat > ~/Library/LaunchAgents/local.wincycle.plist <<'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>Label</key>
	<string>local.wincycle</string>
	<key>ProgramArguments</key>
	<array>
		<string>/Users/YOUR_USERNAME/Applications/WinCycle.app/Contents/MacOS/WinCycle</string>
	</array>
	<key>RunAtLoad</key>
	<true/>
	<key>KeepAlive</key>
	<false/>
</dict>
</plist>
EOF
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.wincycle.plist
```

## Устройство

Один файл, `main.swift`, без зависимостей за пределами AppKit.

- **Список окон** — `CGWindowListCopyWindowInfo`, публичный API без каких-либо разрешений.
- **Подсветка** — прозрачные окна-подложки над каждым экраном, которые переставляются сразу под активное окно (`order(.below, relativeTo:)`); отслеживание смены фокуса — уведомление `NSWorkspace.didActivateApplicationNotification` плюс опрос раз в треть секунды (уведомление не ловит переключение между окнами одной и той же программы).
- **Смена активного окна на лету** — при переключении подложка двигается сразу, не дожидаясь опроса, иначе на треть секунды затемнённым оказывалось бы как раз то окно, на которое переключились.
- **Защита от двух копий** — при старте приложение проверяет, не запущена ли уже другая копия, и выходит, если да.

Никаких приватных или недокументированных API — только то, что публично в заголовках AppKit/CoreGraphics.

Подробное устройство, разбор уже допущенных ошибок и порядок проверки изменений — в **[DESIGN.md](DESIGN.md)**. Читать перед тем, как что-то менять.

## Ограничения

- Только macOS. Собрано и обкатано на macOS 26/27 (Tahoe/бета), минимальная версия в `Info.plist` — 13.0, но на более старых версиях не проверялось.
- Несколько мониторов поддерживаются (подложка создаётся под каждый `NSScreen`), но обкатано на связке из одного экрана.
